请将以下信息发送到 [nuo66688@163.com](mailto:nuo66688@163.com)，我会尽快配置并回复：

- **ASN**: 您的 AS 号
- **Public IP**: 您的公网 IP（IPv4 / IPv6）
- **DN42 IPv4**: 您在 DN42 中的 IPv4 地址
- **DN42 IPv6**: 您在 DN42 中的 IPv6 地址（如有）
- **IPv6 本地链路**: 您的 IPv6 link-local 地址（如有）
- **Peer 节点**: 您要 Peer 的节点名称（见下方服务器列表）
- **WireGuard 公钥**
- **WireGuard 监听端口**
- **传输路由**: IPv4 / IPv6 / both
- **Multi-Protocol BGP**: true（IPv4+IPv6 同一 session）/ false（分开建立）
- **Extended Next Hop**: true / false

> ⚠️ 建议中国大陆服务器与中国大陆服务器进行 Peer，非大陆服务器与非大陆服务器进行 Peer，在避免法律问题的同时可以减少延迟。
